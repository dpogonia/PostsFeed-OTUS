# Posts Feed

A post feed. An OTUS study project: the screen state is kept with Flux.

## What it does

Posts come from jsonplaceholder. An empty list shows a loading indicator. If the network fails, the screen shows the error. A line above the list says whether the data came from the server or from the cache. A post can be marked as a favorite.

## Stack

SwiftUI, Combine, URLSession.

## Run

```bash
git clone https://github.com/dpogonia/PostsFeed-OTUS.git
cd PostsFeed-OTUS
open "OTUS HOMEWORK 7.xcodeproj"
```

Run the **OTUS HOMEWORK 7** scheme on an iPhone simulator.
