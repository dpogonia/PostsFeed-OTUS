# Posts Feed

Лента постов. Учебный проект OTUS: состояние экрана собрано через Flux.

## Что умеет приложение

Посты приходят с jsonplaceholder. Пока список пустой, виден индикатор загрузки. Если сеть не ответила, показывается текст ошибки. Над списком подпись, откуда данные: с сервера или из кэша. У поста можно переключить избранное.

## Стек

SwiftUI, Combine, URLSession.

## Запуск

```bash
git clone https://github.com/dpogonia/PostsFeed-OTUS.git
cd PostsFeed-OTUS
open "OTUS HOMEWORK 7.xcodeproj"
```

Запустите схему **OTUS HOMEWORK 7** на симуляторе iPhone.
